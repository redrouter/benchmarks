# SSE fixtures

`openai-recorded.sse` is adapted from the OpenAI Python SDK's [recorded streaming snapshot](https://github.com/openai/openai-python/blob/c6fc264689d384d5caec150fafa1a9567c4a3f56/.inline-snapshot/external/e2aad469b71d1d4894ff833ea147020a9d875eb7ce644a0ff355581690a4cbfd.bin). `anthropic-recorded.sse` is adapted from the Anthropic Python SDK's [basic response fixture](https://github.com/anthropics/anthropic-sdk-python/blob/4c7b598466b88559583f98216139be8e9b34c1fc/tests/lib/streaming/fixtures/basic_response.txt). Both were retrieved with unauthenticated public GETs. Response text and identifiers were replaced with `sample`; event order, structure and usage counts were retained. The upstream Apache-2.0 licences and copyright notices are in `LICENSE-openai` and `LICENSE-anthropic`.

The `complete` and `error` fixtures are original synthetic transcripts covering reasoning, tools, cache usage, trailing cumulative usage and partial failures. Their Messages event shapes follow the [official streaming reference](https://platform.claude.com/docs/en/build-with-claude/streaming). No fixture requires credentials or an inference call. Text exists only to exercise non-empty delta detection; normalized events and benchmark records never retain it.
